# Build-Log → „Schau mir beim Bauen zu" (Build-in-Public)

> **Zweck:** Jeder nennenswerte Bau-Schritt am AI-Adoption-Studio wird hier so dokumentiert, dass er **direkt als LinkedIn-Post verwertbar** ist. Das Projekt ist Alex' Karriere-Asset — wir zeigen Schritt für Schritt, **was Alex kann** (Vibe Coding / KI-Orchestrierung / Systemdenken). Doku und Content sind dasselbe Artefakt.

## Warum
Der „Schau mir beim Bauen zu"-Teil ist der eigentliche LinkedIn-Hebel: Bewegung, Fortschritt, ehrliche Hürden + Durchbrüche. Nicht das fertige Tool verkauft — der **Weg** verkauft. Die On-Site-Entsprechung ist die Build-Log-/Agents-Sektion der Homepage (kommt später, wenn das Tool steht).

## Ein Eintrag pro Schritt — Format
Datei: `YYYY-MM-DD-kurzer-slug.md`. Drei Blöcke:

### 1. Build-Kontext (intern)
Was technisch passiert ist — Commits, Branches, Issues (ALE-…), Entscheidungen. Für uns, nicht für den Post.

### 2. 🔵 LinkedIn-Post (copy-paste-fertig)
- **Hook** (erste 1–2 Zeilen, < 210 Zeichen) — entscheidet alles. Hook-Formeln: persönliche Story / kontraintuitiv / überraschende Zahl / Vorher-Nachher.
- **Body** — eine Aussage pro Zeile, Leerzeile zwischen Absätzen. Story + Lektion (höchste Engagement-Form). Ehrlich: Fehler UND Durchbruch.
- **CTA** — eine Frage / „Was würdest du ergänzen?".
- **3–5 Hashtags** (festes Kampagnen-Set übernehmen).
- **Link in den ersten Kommentar**, nie in den Post (Algorithmus straft Links).

### 3. Was es über Alex zeigt + Visual-Idee
1 Satz: welche Fähigkeit dieser Schritt belegt. Optional: Idee fürs Bild/Carousel (Studio-Brand).

## Tonalität (Pflicht)
Personal Editorial („Learning in Public") · cool, provokant, faktenbasiert · echte Umlaute ä/ö/ü · **kein** Corporate-Speak · keine erfundenen Zahlen. Drei Tonalitäts-Modi der Kampagne beachten (Personal Editorial 80% / Strategist Memo 15% / Editorial Essay 5%).

## Cadence
Nach jedem nennenswerten Merge/Meilenstein ein Eintrag. Posten 3–5×/Woche (Di–Do 7–8 / 12 / 17 Uhr). Tracking: **EPIC-15 · Build-in-Public** in Linear. Speist die [LinkedIn-Kampagne](../../.. ) (26 Posts / 90 Tage).
